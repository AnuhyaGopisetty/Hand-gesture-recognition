**✋ Hand Gesture Recognition**
📌 **About the Project**

Hand Gesture Recognition is an AI-based web application that detects hand movements in real time using a webcam. It uses Google MediaPipe Hand Landmarker to identify hand landmarks and JavaScript to recognize different hand gestures.

The application provides a simple, interactive interface for detecting and displaying gestures.

✨ **Features**
📷 Real-time hand detection using a webcam
🤖 AI-powered hand landmark tracking
✋ Open Palm recognition
✊ Fist recognition
👍 Thumbs Up recognition
✌️ Peace Sign recognition
🎯 Visual hand landmark and connection drawing
▶️ Start and stop camera controls
💻 Simple and responsive user interface

🛠️ **Technologies Used**
HTML5  
CSS3   
JavaScript (ES Modules)   
Google MediaPipe Tasks Vision  
WebRTC Camera API   

⚙️ **How It Works**
The application accesses the webcam with the user's permission.
MediaPipe detects the hand and identifies 21 hand landmarks.
JavaScript analyzes landmark positions to classify gestures.
The detected hand landmarks are drawn on the video feed.
The recognized gesture is displayed on the screen.
🚀 How to Run
Clone or download this repository.
Open the project folder in Visual Studio Code.
Run index.html using Live Server.
Allow camera access when prompted.
Show your hand in front of the camera to test the gestures.

📋 **Requirements**
A modern web browser
A working webcam
An internet connection to load MediaPipe and its AI model
Camera permission enabled
HTTPS or localhost for camera access
🎯 **Project Objective**

The objective of this project is to demonstrate real-time hand detection and basic gesture recognition using computer vision and web technologies.
